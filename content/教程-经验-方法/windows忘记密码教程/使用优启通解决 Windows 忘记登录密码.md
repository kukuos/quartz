## 前言

当 Windows 电脑忘记登录密码、又无法进入桌面时，可以借助 **优启通（EasyU）** 制作一个 U 盘 PE 启动盘，从 U 盘启动进入 PE 系统，再用 PE 内置的密码工具直接把账户密码清空或重设。

本方法适用于 Windows 7 / 8 / 10 / 11 的**本地账户**。

> ⚠️ 注意
> - **微软在线账户**（用邮箱登录的账户）不能靠本地清除密码，需要到 [account.microsoft.com](https://account.microsoft.com) 在线重置。
> - 只用于自己的电脑或已获授权的设备，切勿用于非法用途。
> - 若系统盘开启了 **BitLocker 加密**，操作前需先准备好恢复密钥，否则可能无法读取系统盘。

## 准备工作

| 需要的东西     | 说明                                                 |
| --------- | -------------------------------------------------- |
| 一个 U 盘    | 容量 ≥ 8GB，制作时会**格式化**，请提前备份里面的数据                    |
| 一台能上网的电脑  | 用来下载优启通、制作启动盘                                      |
| 优启通 EasyU | 打开 优启通官网( https://www.uqitong.com/ ) 选择**X86版** 下载 |

## 第一步：制作优启通 U 盘启动盘

1. 在能正常使用的电脑上，下载并打开 **优启通 EasyU**。打开会出现捐赠窗口可以关闭不影响使用。
2. 插入 U 盘，软件会自动识别。
3. 在主界面确认在 **"默认模式"** 
4. 确认要写入的 U 盘盘符**无误**，点击 **"一键制作启动U盘"**。
5. 弹出格式化警告，确认 U 盘数据已备份后点击 **"确定"**，等待进度条完成。
6. 提示制作成功后即可拔出 U 盘。

## 第二步：从 U 盘启动进入 PE

1. 把制作好的 U 盘插到**忘记密码的那台电脑**上。
2. 开机时连续按 **启动快捷键**，调出启动菜单（Boot Menu），选择你的 U 盘启动。

常见品牌的启动快捷键：

| 品牌          | 启动菜单键                    |
| ----------- | ------------------------ |
| 华硕 ASUS     | `F8` / `Esc`             |
| 联想 Lenovo   | `F12`                    |
| 惠普 HP       | `F9`                     |
| 戴尔 Dell     | `F12`                    |
| 宏碁 Acer     | `F12`                    |
| 微星 MSI      | `F11`                    |
| 技嘉 Gigabyte | `F12`                    |
| 组装台式机       | 多为 `F11` / `F12` / `Esc` |
![[Pasted image 20260825000122.png]]

> 如果按快捷键没反应，可能开启了 **Secure Boot（安全启动）** 或 **Fast Boot（快速启动）**，需进 BIOS（开机按 `Del` / `F2`）把它们关闭后再试。

![[Pasted image 20260825001240.png]]
> *截图：开机启动菜单（Boot Menu），选中带 UEFI 字样的 U 盘*

3. 在启动菜单里选中 U 盘（名称一般带 `UEFI` 或 U 盘品牌字样），回车。提示如果名称UEFI进不去可以选择U 盘品牌字样尝试进入。
4. 进入优启通菜单后，通过上下方向键选择 **"Win10 PE"** ，回车，等待进入 PE 桌面。

![[Pasted image 20260825002443.png]]
> *截图：优启通启动菜单，选择 Win10/Win11 PE*

## 第三步：在 PE 里修改 / 清除密码

进入 PE 桌面后，优启通内置了修改密码的工具，常见有两种方式：

### 方式 A：使用"密码修改"工具（推荐，最简单）

1. 双击桌面的 **"Windows 登录密码修改"**（不同版本可能叫 `NTPWEdit`、`Windows 密码清除`、`Password Reset`）。
2. 工具会自动定位系统盘的 `SAM` 文件（一般路径为 `X:\Windows\System32\config\SAM`，`X` 为系统盘符）。若没自动识别，手动选择系统盘上的该文件后点 **"打开"**。
3. 在用户列表里选中**要修改的账户**（如 `Administrator` 或你的用户名）。
4. 点击 **"修改密码"** 两个输入框留空点"确认"即清空密码， 或直接设一个新密码。
5. 点击 **"保存更改"**（Save / Write），提示成功即可。

![[Pasted image 20260825004721.png]]
> *截图：PE 内密码工具，选中账户后清除/重设密码并保存*

---

## 第四步：拔盘重启，用新密码登录

1. 关闭密码工具，点击 PE 开始菜单里的 **"重启"**。
2. 电脑重启时**拔掉 U 盘**，让它从硬盘正常启动。
3. 回到 Windows 登录界面：
   - 如果第三步**留空**了密码，登录框留空**直接回车**即可进入。
   - 如果**设了新密码**，输入新密码登录。

大功告成 ✅

## 常见问题

- **进不了启动菜单 / 认不到 U 盘**：进 BIOS 关闭 Secure Boot、Fast Boot，把 USB 设为第一启动项；U 盘换到主板后置 USB 口（台式机）再试。
- **PE 里看不到系统盘**：可能是硬盘为 RAID / VMD 模式或系统盘加了 BitLocker，需要在 BIOS 关掉 VMD / RAID 或先解密。
- **清除后仍要输密码**：确认你选的是**当前正在登录的那个账户**，且保存更改成功；有些账户是微软在线账户，需在线重置。
- **改的是微软账户**：本地清除无效，请到微软官网在线重置密码。
